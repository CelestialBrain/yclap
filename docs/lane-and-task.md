# Lane & task map — Ateneo Youth CLAP

**Purpose:** Use every course strength so the project is hard enough to matter and wide enough that no one is decorative.  
**Default product:** Gargar pilot (+ EcoWaste evidence).  
**Manager / builder:** Mar Angelo Revelo — accepts any idea the room chooses; owns integration.

---

## Operating rules

1. **One geography** — Ateneo + one Pasig/QC node.  
2. **One hero metric** — kg diverted (and users).  
3. **No lane is optional** — Build without Science is hype; Science without Mobilize is a paper; Story without field proof is theater.  
4. **Idea intake open** — If the cohort picks flood/heat/organics over Gargar, Build re-scopes; lanes stay.
